# 系统设置中的智能体形象与昵称

状态：按用户确认的“所有形象共用一个昵称”实现
日期：2026-10-06

## 目标

把 7 款智能体形象的选择从聊天面板移到系统设置；增加跨形象共用的昵称；设定保存后桌面吉祥物即时更新。

## 方案

- 系统设置页显示当前形象预览、7 款形象选项和共用昵称输入框。
- 保留既有 `agentAvatarIdx` localStorage 键，迁移入口不重置用户已选形象。
- 昵称和形象选择都保存在当前浏览器的 localStorage；通过同页自定义事件和跨页 `storage` 事件同步到吉祥物。
- 聊天面板移除形象切换按钮；昵称显示在吉祥物名牌，名称不会随形象切换而变化。
- 此偏好不涉及 AGH、模型凭据或后端；智能体聊天和诊断仍遵守 AGH readiness。

## 验收

1. 系统设置能预览并切换全部 7 款形象，选择后预览和吉祥物即时更新。
2. 用户可保存一个共用昵称；切换不同形象后昵称保持相同。
3. 刷新后保留形象和昵称；原有形象索引继续有效。
4. 聊天面板不再提供切换入口；偏好设置不改变 AGH 或模型状态。
