## 三、决策项：智能体数量（用户问：6 个偏多/偏少/正好？）

**结论：6 个偏多且多数不该是"智能体"；建议收敛为 2 个真实智能体 + 若干算法面板。**

逐个评估（结合本项目代码与 Agnes 能力）：

| 理想图智能体 | 是否需要 LLM 智能体 | 理由 |
|---|---|---|
| 诊断智能体 | ✅ **保留（核心）** | 已存在：假设树+取证+交叉验证+置信度，是比赛故事主线的差异化能力 |
| 工单派发智能体 / 工单智能体（图中出现两次） | ⚠️ **合并为第 2 个** | 诊断结论→工单生成→闭环跟踪，可作为独立轻智能体（第二次 Agnes 调用）或诊断智能体的第二阶段；注意理想图里它重复出现了两次，本身即设计冗余 |
| 巡检智能体 | ❌ 改为"规则引擎/监控服务" | 定时采样+阈值判断是确定性任务（phmlite 的 maybe_alarm 已实现），用 LLM 巡检只会更慢更贵且不可解释；界面上可作为工作流的一个**阶段**展示 |
| 预测防护（预测维护）智能体 | ❌ 改为算法面板 | 剩余寿命=趋势外推算法的输出；让 LLM"预测"会产出无法验证的话术，恰是用户反对的"假"。展示为"预测性维护建议"面板，数据来自拟合算法，标注估算置信 |
| 能耗优化智能体 | ❌ 建议删除 | 无数据通道，做出来必然是硬编码假数字 |

Agnes API 能力层面：单个 API key 技术上可并发多个智能体会话（每个=提示词策略+工具集+循环），但**token 成本、速率限制、5 分钟演示时延随时调用量线性增长**；评审更看重证据链真实可验证，2 个各司其职、每次调用可回放的智能体，远胜 6 个并行"人设"。演示编排上也建议串行触发而非 6 路并发。

### 7.1 仿真通道扩展范围 → 复用率核算（回答用户"我们复用了旧仓库的百分之多少"）

实测数据：旧算法服务 AlgorithmWeb 共 **39 个可用接口**、仅 feature_calculate.py 一个文件就有 **20+ 个时域/积分特征函数**（通带RMS、速度RMS、加速度RMS、冲击脉冲值、峰值因子、位移特征、加速度积分→位移、Hilbert 包络、带通滤波等）；图谱族（伯德图/瀑布图/级联图/极坐标图/轴心轨迹/全息谱）以及应力波、声学、电流谱、PCA 建模、大机组策略各有独立模块。

phmlite/dsp.py 现状：**8 个函数**（RMS/峰峰值/峭度/歪度/FFT谱/包络谱/轴承特征频率/波形合成）。

**结论：**
- **算法覆盖面 ≈ 20%**（39 个接口对齐 8 个核心能力；仅时域指标一项，旧仓库 20+ vs 我们 4 个）；
- **图谱族覆盖 0%**（伯德/瀑布/级联/极坐标/轴心轨迹全没有——这些依赖多传感器+键相+位移传感器数据）；
- 已移植部分的**公式与旧仓库 100% 同源**（峭度=标准化四阶矩、包络=Hilbert 解调等定义一致，这是 Task 11 对照验证的基础）；
- 波形合成器（synthesize）是**新写的**，旧仓库没有对应物（它的 mockdata 只是静态 CSV 样例），故障注入能力反而是新版更强。

Task C 扩展（多测点+温度）只是在振动主线上加密通道，覆盖面提升有限（约 +5%），但满足"首页所有卡片实时联动"的展示需求。若要提升对旧仓库的复用率叙事，性价比最高的补充是：**加速度→速度→位移积分链路** 和 **通带RMS/冲击脉冲值** 这几个函数级移植（旧仓库现成公式）。

### 7.2 设备命名分析（待用户最终拍板）

**"调相机"是真实行业术语**：同步调相机（synchronous condenser），电网侧的无功补偿设备，可以理解为电网的"弹簧/稳压器"——在新型电力系统建设下，国家电网在风光大基地（含新疆木垒，正是旧库种子数据里 PLANT16 站点）批量部署调相机站。旧仓库的全部专业词汇——**瓦振、轴振、大机组、伯德图、级联图、极坐标图**（large_unit_algorithm.py 直译就是"大机组算法"）——都是这类大型旋转机组的标准术语，和调相机严丝合缝；这些词放在离心泵上反而不贴（泵多用滚动轴承，讲加速度/包络/冲击脉冲，不讲"瓦"）。

三个候选的定位：

| 候选 | 商业识别度 | 与旧仓库算法/素材匹配 | 备注 |
|---|---|---|---|
| **调相机（同步补偿机组）** | 中（电力行业内高，行业外需要一句解释） | ★★★ 图、数据、术语全对齐 | 可加副标题"电网侧无功补偿机组"解决理解问题；"新型电力系统配套"是当下有热度的商业叙事 |
| 离心泵 | ★★★（人人秒懂，P-101 本身就是泵的管路位号风格） | ★☆ 现有底图是大型机组不是泵；瓦振/轴振词汇不适用 | 选它就得换泵的底图、删掉瓦振类术语 |
| 离心机 | 中下（细分行业设备） | ★★ | 无明显优势，不建议 |

**推荐：调相机，展示名"调相机智能运维平台"，副标题"面向新型电力系统的同步补偿机组状态监测"**——既保住旧仓库全部真实资产的真实性，又是差异化的商业叙事（市面上泵/风机 demo 太多，调相机群监测稀缺）。次选离心泵（需换图换词汇）。
