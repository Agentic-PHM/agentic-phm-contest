# 诊断与导出完成判据（2026-10-14）

完整诊断完成不以“有报告”“工具未报错”或“导出文件生成”为判据。

报告须给出 `diagnosis_status=confirmed|provisional|undetermined` 和 `diagnosis_code=bpfo|bpfi|bpfo_bpfi|unbalance|looseness|undetermined`。旧记录不补造状态或机理，保持历史未核验。

模型无需在Windows命令行手拼evidence_json：存储证据由本run的AGH实际响应及HTTP200审计生成，模型负责结论和机理判断。显式传入旧证据格式仍先校验，但不能替换这些实测观测。取证使用curl --fail-with-body，HTTP失败仍非零，并把错误JSON返回给模型自纠正。

趋势取证使用limit=12，并返回按seed/live/unknown分别计算的完整窗口摘要。这样工具不会因长历史响应被截断而失去可解析证据；界面未给limit时仍取得完整曲线。

确证须成功取得时域、趋势、FFT、包络谱及理论频率。服务端依据本次AGH实际工具响应检查机理支持，不能读取场景真值替代取证。轴承基频容差1.5Hz、峰/底噪至少20；不平衡要求A1X>5×max(A2X,A3X)；松动要求A2X>A1X且A3X>0.5×A1X，与当前只加入2X/3X的合成器一致，不要求半频或轴承特征峰。这是本仿真原型的限定条件，不是经过现场标定的通用工业标准，也不保证诊断正确。

工具缺失或机理未知时可提交说明缺失证据/待复测的保留性报告；不允许自动维修工单，不计完整闭环。报告留档和诊断完成分别为 `report_saved`、`diagnosis_done`。

保留性报告的实际执行及报告写入通过时，标记partial和limited_verified；完整诊断ok仍为false。若缺执行或写入证明，则仍为verification_failed，不能用partial标签掩盖核验失败。

确证文本的一致性按分句及已声明机理检查：单外圈结论可以说明“内圈证据不足，不能确证混合”，不能因此否定外圈确证；对声明机理本身的证据不足、无法确证及未限定对象的拒判仍阻止confirmed。混合结论则必须同时支持内外圈。文本检查不替代实际观测门禁。

完成必须同时满足：唯一报告、唯一智能体工单、非空数值证据、模型标识、至少5次工具调用、当前尝试turn成功结束；准确接口及request run_id、response id/run_id对账、明确成功的工具结果与HTTP200审计。索引落盘失败撤销完成。

同run_id同内容重试返回原id；不同内容返回冲突，不覆盖审计。在线与导出共用 `validate_completion`。导出重建原始执行索引，不相信缓存；不完整结果保留失败材料并退出非零。

可识别的调用仅限一个本机curl请求及已知参数；允许其前面用PowerShell单引号字面量给env变量赋值，再用于data-urlencode参数。不会执行解析得到的内容；表达式、其它前置命令、输出替换及组合请求都不能作为成功调用证明。

19例重测保留旧基线。工具失效例须实际命中目标503（本run_id的HTTP审计），否则标无效、不给降级分；前置/会话失败仍计入总体失败分母。子集基线仅覆盖同一子集，低转速正常例实际设置rpm。基线仍是固定种子参考算法，与在线波形不完全同源，不能宣称公平统计优势。
